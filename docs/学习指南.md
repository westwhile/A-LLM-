# 仓库学习指南：用本项目建立金融 / 量化 / 统计知识储备

> 本指南回答三个问题：这个仓库里有哪些知识、按什么顺序学、学到什么程度算会。
> 所有路径相对 `A-LLM-` 项目根。配套路线图见 `docs/plans/总体计划.md`。

## 0. 这个仓库为什么值得学

本仓库不是"策略收益展示"，而是一个**可审计的量化研究工程**：它把学界和业界的标准做法（PIT 时间一致性、walk-forward 样本外验证、事件驱动回测、多重检验校正、证据哈希留痕）落地成了可运行代码。学它的正确方式不是从头到尾读代码，而是：**先在文档里理解概念 → 在 notebook 里跑通流程 → 回代码里看工程实现 → 用检验题自测**。

## 2. 推荐学习路径（四阶段）

### 阶段一：建立概念框架（建议 3–5 天）

1. 读 `README.md`，跑通快速开始（`run-research` 样例模式），对全流程有体感。
2. 精读 `docs/plans/A股多因子量化研究实现计划.md`——这是全仓知识密度最高的文档，含全部因子公式、检验方法、成本参数、面试问答。重点读 §9–34。
3. 读 `docs/data_dictionary.md`，把 12 张表和四日期体系记牢。

### 阶段二：动手跑通流程（建议 4–7 天）

按顺序运行并精读 `notebooks/01`–`07`，每跑一个就对照读对应的 src 模块：

- 01–02 数据获取/清洗 → `data/data_loader.py`、`data_cleaner.py`、`data_quality.py`
- 03 因子构建 → `factors/registry.py`、`factor_processor.py`
- 04 因子检验 → `factor_testing/`
- 05 组合回测 → `backtest/`
- 06 风险归因 → `analysis/`
- 07 LLM 事件 → `llm/`

### 阶段三：精读四大特色模块（建议 1–2 周，最难也最有价值）

1. **PIT 审计链**：`data/pit_audit.py` 六项审计 + `monthly_research.py` 的非重叠标签与留出期规则。
2. **walk-forward 与预注册**：`factor_testing/walk_forward.py` + `config/research_protocol.real.yaml` + `config/experiment_registry.csv`。
3. **事件驱动回测**：`backtest/backtest_engine.py` 的订单流和未成交分析。
4. **统计推断链**：`factor_testing/inference.py`（HAC、FDR）→ `time_series/models.py`（DM、SPA、DSR、PBO）。

### 阶段四：表达与自测（持续）

用 `docs/interview_notes.md` 自讲：能对陌生人讲清"为什么中性化、如何避免未来函数、回测有哪些局限"，才算真正掌握。

## 3. 自学检验题（能独立回答才算学会）

**金融**
1. 为什么财务因子不能用"报告期"日期直接对齐到交易日？`usable_date` 为什么取公告日后下一交易日？
2. 为什么用当前中证 500 成分股回测 2015–2020 年会虚增收益？本仓库在哪两个环节防这件事？
3. 涨停板为什么"买不进"而不是"以更贵的价格买进"？代码里如何表达？

**量化**
4. 为什么要做行业和市值中性化？如果不做，因子 IC 可能只是在暴露什么？
5. Q5-Q1 多空价差在 A 股为什么不能直接解释为可交易收益？应该改看什么？
6. walk-forward 里"方向锁定"锁的是什么、防的是什么？
7. 信号日 T 收盘出信号、T+1 开盘成交，这个设计防的是什么偏差？如果 T 收盘成交会引入什么？

**统计**
8. RankIC 为什么比 Pearson IC 稳健？
9. 检验 30 个因子的 IC 显著性时，为什么朴素 t 检验 + 0.05 阈值不可靠？本仓库用了什么校正？
10. DSR（Deflated Sharpe Ratio）相对普通夏普比率多修正了哪两件事？
11. 为什么 HMM 只用 filtered 概率而不用 smoothed 概率做交易信号？

**工程**
12. manifest 里的内容哈希防的是什么？为什么导入目录非空禁止覆盖？
13. 配置契约"未消费键拒绝"解决什么问题？

## 4. 外部资源衔接（按知识域，少而精）

- **量化组合管理**（因子、IC、风险模型的理论根基）：Grinold & Kahn《主动投资组合管理》
- **量化策略实践**：Ernest Chan《Algorithmic Trading》《Quantitative Trading》（回测陷阱、均值回复/动量）
- **因子投资实证**：Clifford Ang《Factor Investing》；AQR 公开研究笔记
- **统计与时间序列**（Kalman/HMM/GARCH 的理论背景）：Hamilton《Time Series Analysis》；statsmodels 官方文档（与本仓库同栈）
- **回测过拟合**：López de Prado《Advances in Financial Machine Learning》相关章节（DSR、PBO 的原始出处）
- **Python 数据处理**：pandas 官方文档（`groupby`、`merge`、`resample` 三件套熟练即可覆盖本仓库 90% 的数据操作）

学习方法建议：外部资源只读与本仓库模块直接对应的章节，读完后回到仓库找对应实现——"书上的公式 ↔ 仓库的代码"对照一遍，比单独读书效率高得多。

## 5. 与升级计划的衔接

学习优先级跟随升级路线图（`docs/plans/总体计划.md`）：

1. **当前最该学**：数据源字段语义与 PIT 概念（支撑 P0 真实数据门禁，你要主导 7 张表的来源确定与签署）。
2. **其次**：状态空间模型与波动建模（Kalman/HMM/GARCH，对应 §3 检验题 10–11）——P1 阶段真实运行前必须懂，否则无法判断模型输出是否合理。
3. **再次**：多重检验与过拟合审计（DM/SPA/DSR/PBO）——P2 晋级审计的理论基础。
4. **远期**：机器学习/深度学习（LightGBM/TCN/PatchTST）——P4 阶段 10 才启动，前置条件未满足前不必投入。
