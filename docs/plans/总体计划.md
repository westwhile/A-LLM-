## 三、升级路线图（P0 → P4，严格按依赖排序）

> 原则（来自 `docs/plans/项目模块总结与改进计划.md` §8）：不优先追求更多因子或更漂亮的样例收益；数据治理优先。

### P0：解锁真实数据门禁（用户主导，AI 辅助）

- **目标**：`data_gate_summary.json` 状态变为 `passed`。
- **要做的事**（详细字段与签署步骤见 `reports/data_sources/真实PIT许可与人工签署执行指南.md`）：
  1. 确定 7 张必需表各自的合法数据来源（Tushare Pro / iFinD / Wind 等授权渠道）。
  2. 按 `reports/data_sources/缺口数据提供规范.md` 模板导出 CSV/Parquet：起点不晚于 2015-01-01，含已剔除、退市和历史状态。
  3. 准备许可摘要与字段/PIT 证据（单位、公告/修订/可用日、生效区间）。
  4. AI 只读预检 → 修复 → 第一次签署（许可入库授权）→ 更新登记表与哈希 → 新批次导入 → 审计归零 → 第二次签署（审计验收冻结）。
- **产物**：7 张表入库 + 两次签署 + `data_gate_summary.status=passed`。
- **需学知识**：数据源字段语义、PIT 四日期体系（学习指南 §1.1、§2 阶段一）。

### P1：真实阶段 2–6（P0 完成后）

- **目标**：真实月度样本 → 诊断基准 → Kalman/HMM/GARCH-DCC 真实 OOS 比较，≥36 个非重叠 OOS 月。
- **要做的事**：`reports/implementation_status.md` P1 清单（8 项）；`benchmark_returns.csv` 已自动化。
- **产物**：`outputs/monthly/real-*`、`outputs/stage46/real-*` 全套真实产物。
- **需学知识**：状态空间模型与波动建模（学习指南 §1.3、§2 阶段三）——**这是下一步最该学的一块**。

### P2：研究结论链（阶段 7–8 真实运行）

- **目标**：七组消融区分各模块独立增量；DM/SPA/DSR/PBO 过拟合审计；达到预注册门槛才晋级动态方案。
- **需学知识**：多重检验校正与过拟合度量（学习指南 §1.3）。

### P3：工程深化（不阻断主线，P1 后可穿插）

- 冲击成本随流动性分层/市场状态动态化；容量压力测试接入报告。
- Brinson/因子归因、风格暴露完整化；接申万/中信真实行业分类。
- 交易约束真实化：真实 lot size、新股/复牌首日输入列、长期停牌处理。
- LLM 真实文本源接入与人工复核标签集。

### P4：深度学习实验轨（阶段 10，暂缓）

- LightGBM 时序基准、TCN、PatchTST。**前置条件**：≥8 年合格真实数据 + PIT 问题归零 + 传统模型基线完成。前置条件未满足前不投入。

## 四、用户行动项（按时间顺序）

1. 【现在】选择数据源并开通授权（7 张表的合法来源是唯一的硬卡点）。
2. 【现在】按学习指南 §2 阶段一建立概念框架（3–5 天）。
3. 【数据到位后】按 `真实PIT许可与人工签署执行指南.md` 完成两次人工签署。
4. 【P0 通过后】监督 AI 跑 P1 真实阶段 2–6，同时学状态空间模型。
5. 【持续】所有计划文档只放 `docs/plans/`；新计划先登记到本文件路线图再执行。

## 五、不做清单（防止范围漂移）

- 不做实盘对接；看板只读，不得触发交易。
- 不直接预测股票价格水平、不做高频日内、不做全股票 DCC/VAR。
- 未达晋级门槛时，保留静态方案或"不晋级"结论，不得为了晋级放松门槛。
