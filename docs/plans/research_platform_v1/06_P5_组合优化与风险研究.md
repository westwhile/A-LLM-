# P5 / 科研 R3：组合优化与风险研究实施计划

> 本模块只接收 R2 冻结预测；不得为改善组合结果回到 R1/R2 重新筛选表示或模型。

## 1. 中央研究问题

> 已经通过样本外检验的预测增量，能否在现实约束、估计误差和交易成本下转化为比简单 Top-N/静态风险方案更稳定的组合结果？

P5 不以“模型更复杂”为晋级理由。

## 2. 前置条件

- P1 已有真实静态与动态组合基准；
- R2 已冻结一个预测模型；该模型可以是复杂 ML，也可以是未观察到 ML 增量后的简单基准；
- 预期收益、风险、协方差、成本和约束的时间语义已冻结；
- 回测执行和归因链已通过审计；
- 不涉及券商连接或自动下单。

## 3. 对照阶梯

1. 现有 Top-N 与单票/行业约束；
2. 等权或风险简单缩放；
3. 波动目标/风险预算；
4. 收缩协方差下的均值—风险优化；
5. Black–Litterman 候选；
6. Deep Portfolio 仅在 Black–Litterman 之后作为条件实验；
7. FinRL/强化学习仅作为远期 paper/simulation，不接券商。

每个复杂方案必须相对前一层报告增量和新增失败模式。

## 4. 工作包

### P5-W1：输入不确定性

评估预测误差、排序误差、协方差估计误差和风险模型错设如何传导至权重、换手和集中度。

### P5-W2：约束合同

冻结：权重和、现金、杠杆、单票、行业、最小持仓、换手、参与率、手数、停牌、涨跌停、ST、上市/退市和不可成交处理。

### P5-W3：简单组合基准

复用相同预测与执行条件，建立 Top-N、等权、波动缩放和风险预算基准。简单模型是正式候选，不是占位符。

### P5-W4：Black–Litterman 候选

明确市场先验、观点映射、观点置信度来源、风险厌恶和协方差估计。模型置信度不能直接当作观点置信度，必须校准或做敏感性分析。

### P5-W5：动态风险与状态

评估 Kalman/HMM/GARCH/DCC 产生的权重、状态和波动信息在组合层的独立增量，不重复使用未来状态或 smoothed probability。

### P5-W6：执行压力测试

- 成本、滑点、印花税和冲击；
- 延迟 1/2/3 日；
- 参与率、流动性分层和极端市场；
- 停牌、涨跌停、复牌、退市和未成交；
- 容量与集中度压力。

### P5-W7：绩效与风险归因

报告并对账：资产、行业、因子、信号桶、状态、成本、持有期、回撤和尾部日贡献。gross/net 与组合总 PnL 必须一致。

## 5. 主要指标

- 年化/累计收益、波动、Sharpe、Sortino、Calmar；
- 最大回撤、恢复时间和尾部损失；
- 主动收益、跟踪误差、信息比率；
- 换手、成本、未成交、现金和参与率；
- 集中度、行业/因子暴露和容量；
- 年度、滚动和市场状态稳定性；
- 预测增量到经济增量的损耗分解。

## 6. 晋级原则

复杂组合只有在以下条件同时满足时才晋级：

- 相对简单对照的改进跨多个 OOS 窗口稳定；
- 成本后仍成立；
- 不依赖少数极端日期；
- 换手、集中度和容量未失控；
- 权重对预测/协方差扰动不过度敏感；
- 过拟合审计和最终留出期门禁通过。

否则保留简单组合。

## 7. 验收标准

- [ ] 完整时间线与执行假设可审计；
- [ ] 所有方案共享相同数据、预测和成本条件；
- [ ] 约束、未成交和现金处理完整；
- [ ] gross/net 与归因总和对账；
- [ ] 压力测试和参数敏感性完成；
- [ ] 估计误差与模型风险有量化说明；
- [ ] 结论可为“不采用复杂优化”；
- [ ] 输出只作为 Research Package 候选，不触发真实执行。

## 8. 远期边界

强化学习需要单独的环境有效性、离线评估、行为策略偏差、奖励设计和交易安全审查。当前 P5 不实现 RL，也不把历史回测中的 `buy/sell/hold` 视为真实执行授权。
