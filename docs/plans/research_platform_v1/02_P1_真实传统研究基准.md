# P1：真实传统研究基准实施计划

## 1. 目标

使用冻结的真实 PIT 数据建立透明、可复现的传统研究基准，回答现有因子、动态权重、市场状态和波动控制是否具有真实样本外证据。P1 允许结论为“不晋级”。

## 2. 前置条件

- P0 已 `accepted`；
- 数据与协议哈希已签署；
- `data_gate_summary.status=passed`；
- 2024-01-01 起最终留出期仍保持隔离；
- 实验登记表已冻结候选模型、参数网格、指标和晋级阈值。

## 3. 研究对象与时间协议

- 研究股票池与主基准：按 `research_protocol.real.yaml`，当前主基准为 `000905.SH`；
- 数据预热：不晚于 2015-01-01；
- 模型评估区间：2018-01-01 至 2023-12-31；
- 最终留出期：2024-01-01 起；
- 频率：月度信号，下一交易日执行；
- 目标：相邻月末非重叠收益；
- 最低证据：至少 36 个非重叠 OOS 月。

## 4. 工作包

### P1-W1：月度研究样本

生成并检查：

- `monthly_factor_ic.csv`；
- `monthly_factor_returns.csv`；
- `monthly_state_variables.csv`；
- `benchmark_returns.csv`；
- 样本摘要、输入哈希和历史成员覆盖。

检查信号日、执行日、标签结束日和可用日；任何交叉窗口标签、随机切分或未来成分均阻断。

### P1-W2：透明静态基准

至少包含：

- 单因子 IC/Rank IC 与分组收益；
- 因子方向锁定；
- 等权或静态因子组合；
- 12/24 月历史 IC 权重与 EWMA；
- 不使用未来状态的简单风险缩放。

### P1-W3：时序诊断与简单预测基准

执行平稳性、自相关、ARCH、结构突变和缺失诊断。比较简单预测基准，并记录失败状态，禁止静默降级。

### P1-W4：阶段 4–6 动态模型

- Kalman：只使用 `availability_date < test_date` 的 IC；
- HMM：只使用 filtered probability，不使用 smoothed probability；
- GARCH/GJR-GARCH：比较波动预测与目标偏差；
- DCC：仅用于小型因子协方差，不扩展为全股票矩阵。

### P1-W5：阶段 7 消融

使用预注册的七组组合，分别识别动态权重、状态调整和波动控制的独立增量。所有组共享数据、时间、成本和执行约束。

### P1-W6：阶段 8 晋级审计

执行预测检验、DM/SPA、DSR/PBO、试验登记覆盖和晋级门禁。模型未达到门槛时保留静态方案或“不晋级”。

### P1-W7：一次性最终留出期

只有模型选择与全部门槛冻结后，才能一次性打开 2024-01-01 起留出期。留出结果不得用于重新选择参数或模型。

## 5. 数据与因子验收

- 每个因子有公式、字段、可用时点、缺失规则、去极值、标准化和中性化定义；
- 报告按日期、行业、市值和缺失模式展示覆盖率；
- 财务修订、历史成分、停牌、ST、涨跌停和退市按 PIT 语义处理；
- 异常检测只生成审计标记，不自动删除观测。

## 6. 回测与归因验收

- 下一交易日执行，成本、滑点、税费、手数、停牌和涨跌停约束明确；
- 报告 gross/net、换手、参与率、现金、未成交原因和容量压力；
- 年化、复利、基准日期、风险自由利率和 inactive period 口径固定；
- 个股、行业、市值、因子、成本和回撤归因可与组合总 PnL 对账；
- 延迟 1/2/3 日、成本和参与率敏感性完整。

## 7. 核心产物

- 冻结的真实月度输入与 manifest；
- 因子诊断、时序诊断与简单基准；
- Kalman/HMM/GARCH/DCC 预测与审计；
- 七组消融、成本敏感性和执行合规；
- 过拟合与晋级结论；
- 最终研究报告与 `evidence_manifest.json`；
- `Research Package` 上游输入候选，但此阶段不要求包合同已实现。

## 8. 验收标准

- [ ] 所有输入绑定 P0 冻结版本；
- [ ] 至少 36 个非重叠 OOS 月；
- [ ] 训练截止日早于预测目标日；
- [ ] 最终留出期未参与模型选择；
- [ ] 成本、执行约束、消融和过拟合审计完整；
- [ ] 归因可与组合收益对账；
- [ ] 结论明确为晋级、不晋级或证据不足；
- [ ] 不把多空诊断曲线表述为 A 股可交易做空收益；
- [ ] 不把回测结果表述为个人可获得收益。

## 9. 停止条件

若数据门禁失效、OOS 月不足、标签重叠、最终留出期污染、执行合规失败或归因无法对账，停止研究结论链并回到对应上游修复，不进入 ML Alpha。
