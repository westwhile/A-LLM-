# 模块 09：另类数据与多模态计划

> 优先级：C；探索支线。先证明数据合法、持续、PIT 和有经济含义，再讨论视觉/多模态模型。

## 1. 中央问题

卫星、网页、招聘、供应链、社交媒体或图像数据是否在价格、财务、新闻和行业信息之外提供可重复的增量，而不是昂贵、稀疏、难授权的噪声？

## 2. 数据源进入门

- 获取与研究使用许可、个人/商业数据合规、转载/发布边界；
- 历史覆盖、更新频率、供应商变更、修订和幸存者偏差；
- `captured_at / published_at / available_at` 可追溯；
- 实体/地理位置到上市公司的映射有时间版本；
- 成本、下载容量和可持续获取经过评估；
- 未获联网数据拉取授权时只做合同、样例或公开静态数据研究。

## 3. 方法阶梯

### M0 单一数据源可行性

- 先选一个经济机制明确的源，例如招聘强度、公告附件图表或公开工厂活动指标；
- 使用透明统计特征和人工验证；
- 不同时启动卫星、社交和网页三类源。

### M1 图像表示

- 预训练 CNN/ViT embedding + 简单回归；
- 需要图像时间、云层/拍摄条件、区域裁剪和公司映射审计；
- 图像模型只输出可解释中间量（车辆数、灯光、施工变化等）再进入 Alpha。

### M2 多模态融合

- late fusion 作为基准：各模态单独预测后组合；
- early/joint transformer 只有样本量充分后进入；
- 每个模态做缺失标志和独立消融，避免模型仅识别数据供应状态。

## 4. 实验与研究设计

- 明确机制链：原始观测 → 企业经营指标 → 市场预期 → 收益；
- 对照同一公司/行业的公开传统指标；
- 主要指标包括中间量标注准确率和最终 OOS 增量；
- 时间、地区、行业外推分开报告；
- 负对照：随机地块、未来图像、错配公司、云层/分辨率代理、缺失模式。

## 5. 退出门

- 来源合法、持续且历史 PIT 可验证；
- 中间经济变量可由人工样本验证；
- 在已有信息集之上有独立增量；
- 获取/标注成本与科研价值相称；
- 任一门失败则停止，不为“多模态”标签继续扩大数据范围。

## 6. 交付物

- `AlternativeDatasetCard`、许可与时点审计；
- 实体/地理映射表及人工样本；
- 单模态基准、多模态消融和成本表；
- 不进入 PFROS 的原始敏感数据说明。
