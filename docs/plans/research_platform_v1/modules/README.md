## 2. 依赖主链

```text
真实数据/PIT验收
  → 离线特征库 + 实验登记
  → 透明传统基准
  → 结构化 ML Alpha + 过拟合审计
  → LLM 文本增量 / 因果机制（两条独立研究线）
  → 组合优化 + 风险/压力测试
  → Research Package
  → PFROS 登记、人工决策与复盘

另类数据 / 知识图谱 / 基础模型 / Agent / 合成数据
  = 只有主链门禁通过后才允许进入的探索支线
```

## 3. 单模块学习—研究—实现循环

1. 阅读模块中的“先修与必读”，形成概念卡和公式复现；
2. 把中央问题写成可证伪假设，登记数据、切分、基准、指标和停止条件；
3. 先实现最小方案，不直接进入深度模型或复杂平台；
4. 完成泄漏、负对照、消融、成本和稳健性检查；
5. 形成模块研究备忘录，选择 `支持 / 不支持 / 证据不足`；
6. 只有通过本模块退出门，才创建下一模块实现任务。

## 4. 共用红线

- 任何异常模型不得自动删除或修正原始数据；
- 任何合成数据不得替代真实数据验收或真实市场结论；
- 任何 LLM、Agent、RL 或 PFROS 模块不得自动下单；
- 任何模型升级都必须与简单基准比较，并登记全部试验；
- 文献状态为“待核验”的条目不得直接进入投稿引用表。
