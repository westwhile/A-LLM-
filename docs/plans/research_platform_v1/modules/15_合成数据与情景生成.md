# 模块 15：合成数据与情景生成计划

> 优先级：C；合成数据只用于测试、稀有情景和压力研究，不得替代真实数据验收、OOS 证据或最终留出期。

## 1. 中央问题

统计模拟、bootstrap 或生成模型能否扩大已知风险情景覆盖、提高工程测试和压力测试质量，同时不制造虚假的可盈利证据？

## 2. 使用场景

- PIT/回测单元测试和受控泄漏注入；
- 相关性趋一、波动聚集、流动性枯竭和跳跃情景；
- 模型稳健性、风控阈值和恢复演练；
- 隐私研究的概念验证，但不默认认为生成数据已经匿名。

禁止：在合成数据上验证 Alpha 后宣称真实市场有效；用生成数据补足真实 OOS 月数；把生成样本放入 final holdout。

## 3. 方法阶梯

### M0 可解释模拟

- GBM/GARCH/状态切换、copula、block bootstrap、历史重放；
- 每个参数与情景有明确含义；
- 优先作为测试 oracle。

### M1 受约束情景生成

- 指定边际、相关、尾部、停牌/涨跌停和制度约束；
- 评价目标是风险覆盖，不是视觉相似。

### M2 TimeGAN/深度生成

- 与 M0/M1 比较尾部、依赖和下游任务；
- 防止 mode collapse、记忆训练样本和泄漏；
- 训练窗口与评估窗口分离。

## 4. 实验与评价协议

- fidelity：边际分布、ACF、波动聚集、相关和尾部；
- diversity：状态/极端路径覆盖与 mode collapse；
- utility：测试能否发现已知缺陷、压力指标是否稳定；
- privacy：最近邻/成员推断风险（若涉及敏感数据）；
- downstream 预测提升不能作为真实市场证据，只能说明训练辅助效果。

负对照：重放训练数据、独立白噪声、只匹配均值方差、删除危机状态。

## 5. 实现块

1. `ScenarioDefinition` 与 synthetic 标记；
2. 透明模拟库和固定 seeds；
3. 统计/制度约束检查；
4. 可选 TimeGAN；
5. fidelity/diversity/privacy/utility 报告；
6. 压力结果写入 Risk Package，但与真实历史结果分栏。

## 6. 退出门

- 每个生成样本全链路标记 synthetic；
- 能覆盖透明方法未覆盖的已定义风险情景；
- 不记忆或泄露敏感训练样本；
- 不影响真实数据成熟度和市场证据等级；
- 深度生成无增量时保留透明模拟。
