# 模块 08：风险模型、市场状态与压力测试计划

> 优先级：B；对应 P5 和 PFROS M4–M6。风险智能先解释与约束，再考虑 Agent。

## 1. 中央问题

策略风险来自哪些可解释暴露、相关结构、市场状态和尾部情景？动态风险方法能否相对透明基准提高 OOS 稳定性，而不只是事后解释回撤？

## 2. 基准层

- 波动、下行风险、最大回撤、VaR/ES、beta；
- 行业、规模、价值、动量、流动性和个股集中度；
- 风险贡献、相关性、换手、容量和不可交易暴露；
- 历史情景重放与参数压力测试。

## 3. 方法阶梯

### M1 透明动态风险

- shrinkage covariance、EWMA/GARCH/DCC；
- Kalman 动态暴露；
- HMM 状态识别必须使用训练窗口拟合并处理标签置换。

### M2 latent risk factors

- PCA/统计因子作为基准；
- AutoEncoder/条件资产定价模型作为进阶；
- latent factor 需要与可解释暴露关联，不能凭命名解释为“AI 因子”。

### M3 压力测试

- 历史重放：流动性枯竭、波动跃升、行业集中、相关性趋一；
- 参数情景：收益下修、波动/相关/成本上调、成交率下降；
- 合成情景只补充覆盖，不能替代真实历史表现。

### M4 Risk Agent

- 输入只读的组合、市场、事件和风险证据；
- 输出风险摘要、证据引用、不确定性和待人工处理项；
- 与模板化报告比较事实准确率和遗漏率；
- 不生成订单，不修改风险预算，不自动触发执行。

### M5 Deep Hedging（远期）

- 原论文主要针对含交易成本的衍生品对冲；迁移到股票暴露控制必须重新定义任务；
- 没有期权/动态对冲需求时不进入实现主线。

## 4. 实验设计

- 状态模型与静态风险预算 OOS 对比；
- 风险模型预测误差、校准和权重稳定性；
- 状态持续期、标签稳定、不同初值和危机窗口敏感性；
- 风险 Agent 使用冻结事实题库：数值准确、引用覆盖、幻觉、遗漏和建议越权；
- 负对照：随机状态、未来状态、移除危机期、相关矩阵扰动。

## 5. 交付物

- `RiskSnapshot`、`StressScenario`、`RiskAlertCandidate` 合同；
- 风险暴露/贡献/状态/压力报告；
- 动态模型与透明基准对比；
- Agent 事实题库和越权测试；
- PFROS 可消费但不可自动执行的风险摘要。

## 6. 退出门

- 所有风险指标可从冻结持仓和市场数据复算；
- 动态模型在多个 OOS 窗口改善预测或风险控制；
- 压力情景的假设、范围和不可比性已披露；
- Agent 输出有引用且人工批准不可绕过；
- 无增量时保留透明风险基准。
