# 统一门禁与证据矩阵

## 1. 目的

本矩阵统一 A-LLM、Research Package 与 PFROS 的状态判断。任何阶段只有在当前证据和必要人工批准同时存在时才能晋级。

## 2. 证据等级

| 等级 | 含义 | 允许用途 | 禁止用途 |
|---|---|---|---|
| `rejected` | schema、哈希、许可、PIT、方法或证据失败 | 保存拒绝原因 | 研究解释、决策候选 |
| `engineering_valid` | 代码、配置、测试和工程运行成立 | 学习、合同测试、sample 演示 | 真实市场结论 |
| `data_accepted` | 许可、PIT、质量、覆盖和冻结验收 | 真实数据描述、诊断 | 模型有效或投资结论 |
| `market_evidence_eligible` | 真实 OOS、成本、消融、过拟合和留出期通过 | 进入决策证据候选 | 自动批准或执行 |

## 3. 阶段门禁

| Gate | 进入条件 | 必需证据 | 人工批准 | 失败结果 |
|---|---|---|---|---|
| G0 当前状态确认 | 目标路径与工作树已盘点 | status、diff、文件清单 | 否 | 停止写入/扩大范围 |
| G1 数据来源许可 | 表级来源、许可、PIT、单位完整 | review、registry、许可摘要 | 用户 | 禁止真实导入 |
| G2 数据冻结 | manifest 与数据哈希稳定 | manifest、SHA-256、冻结清单 | 用户 | `engineering_valid` 上限 |
| G3 真实数据质量 | blocking=0，专项审计非空 | gate summary、五项审计、warning 说明 | 用户终审 | 禁止真实研究 |
| G4 研究协议冻结 | 问题、窗口、模型、指标、阈值固定 | protocol、experiment registry | 用户/研究负责人 | 禁止模型选择 |
| G5 真实 OOS 研究 | ≥36 非重叠 OOS 月，成本/执行完整 | run、预测、回测、归因 | 独立复核 | 不得晋级模型 |
| G6 过拟合与留出期 | 消融、DSR/PBO 等通过，一次性留出 | promotion audit、holdout receipt | 用户 | 保留简单模型/不晋级 |
| G7 Research Package | schema、哈希、许可、成熟度通过 | package manifest、validator receipt | PFROS 接受 | 拒绝包 |
| G8 PFROS 决策候选 | 可信账本、对账、脱敏比较完成 | portfolio snapshot、candidate、risks | 用户 | 不进入执行 |
| G9 执行与复盘 | 人工决定与来源事实回流 | approval、source import、review | 用户 | 不写金融事实 |

## 5. 各域最小证据

### 数据

grain、主键、schema、行数、日期、资产范围、单位、复权、公司行动、停牌/退市、PIT、覆盖、warning、manifest 和来源许可。

### 因子

公式、时间戳、可用日、目标、去极值/标准化/中性化、覆盖、IC/Rank IC、分组、衰减、换手、成本和稳健性。

### 模型

数据/特征版本、split、参数空间、种子、训练截止、预测目标、对照、消融、失败记录、OOS 和留出期。

### 回测

信号、决策、订单、执行、持有、估值时间线；成本、税费、手数、现金、停牌、涨跌停、流动性、参与率、未成交和延迟。

### 绩效与归因

gross/net、年化口径、基准、回撤、尾部、换手、成本、资产/行业/因子/状态贡献和总 PnL 对账。

### PFROS

来源、事件、分录、精度、幂等、重放、修正、对账、备份恢复、隐私、人工批准和事实回流。

## 6. 禁止替代关系

- 单元测试不能替代真实数据验收；
- gate summary 不能替代人工冻结签署；
- IC 不能替代可执行组合收益；
- 回测 Sharpe 不能替代过拟合和容量审计；
- Research Package 报告文字不能替代文件哈希与原始证据；
- 模型置信度不能替代投资成功概率；
- 人工批准不能直接替代券商/银行来源事实。

## 7. 状态更新规则

状态更新必须引用文件路径、run_id、时间、哈希、测试和批准。证据过期、文件变化或协议改变时，相关门禁自动回到 `review`，不得沿用旧结论。
