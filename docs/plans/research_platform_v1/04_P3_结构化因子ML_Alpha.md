# P3：结构化因子 ML Alpha 实施计划

## 1. 中央研究问题

> 在相同 PIT 数据、时间切分、交易成本和执行约束下，结构化机器学习模型能否稳定优于线性模型、静态因子组合和现有 IC 权重方案？

P3 的目标是检验增量，不是证明“机器学习必然有效”。

## 2. 前置条件

- P1 真实传统基准已 `accepted`；
- P2 的 Dataset/Feature/Experiment Registry 至少具备可用合同；
- 特征、目标、窗口、参数空间、指标和停止规则已预注册；
- 2024-01-01 起最终留出期仍未用于模型选择；
- 新依赖是否已安装、许可证和环境兼容性已核对，未经批准不联网安装。

## 3. 第一版范围

### 输入

- 已验收的价格量、估值、质量、成长、资金流和风险特征；
- 行业、市值和已冻结市场状态作为控制变量或分层变量；
- 不包含未验收的 LLM 文本 Embedding；
- 不自动使用全部可用列，特征集必须显式登记。

### 目标

- 月度横截面未来收益或排序目标；
- 信号日、执行日、持有期和标签结束日与 P1 保持一致；
- 不使用重叠目标支持可交易累计 PnL。

### 模型

最低对照：

1. 等权/静态因子；
2. 历史 IC 权重；
3. 线性回归或 Ridge；
4. Elastic Net；
5. LightGBM；
6. Random Forest 仅作为可选稳健性模型。

TCN、Transformer、PatchTST 和 AutoEncoder 不进入第一版。

## 4. 实验设计

### P3-E0：数据与特征基线

冻结样本、主键、特征表、覆盖率、时间戳、目标和 split manifest。所有预处理只在训练窗口拟合。

### P3-E1：透明模型基线

运行线性/Ridge/Elastic Net，记录系数、稳定性、预测分布和失败情况。

### P3-E2：LightGBM 主实验

采用时间滚动的训练/验证/测试。超参数空间预注册；禁止根据最终留出期选择参数。

### P3-E3：增量与消融

至少比较：

- 价格量特征；
- 基本面特征；
- 资金流特征；
- 市场状态；
- 全部结构化特征；
- 去掉最强单一特征后的稳定性。

### P3-E4：稳健性

- 年度/市场状态/行业/市值分层；
- 不同训练窗口和持有期；
- 交易延迟、成本和参与率；
- 极端日依赖和缺失模式；
- 特征置换或时间扰动负向检查。

### P3-E5：一次性留出期

模型、参数和晋级阈值冻结后才执行。任何留出期后重新建模必须产生新研究问题和新版本，原结果不得覆盖。

## 5. 评价指标

### 预测层

- Pearson IC、Rank IC、ICIR、方向命中率；
- OOS 损失、校准或排序质量；
- 年度、滚动和状态稳定性；
- HAC/FDR 或预注册统计检验。

### 经济层

- 非重叠分组收益；
- 成本前后收益、换手、容量和延迟敏感性；
- 与静态组合共享的执行约束；
- 最大回撤、尾部期和绩效集中度。

单一 Sharpe 或单一 p 值不能决定晋级。

## 6. 防泄漏检查

- 不使用随机 K-Fold；
- 财务数据按 usable date 严格滞后；
- 横截面预处理在当期可见集合内完成；
- 训练窗口的标签必须在 cutoff 前完整实现；
- 模型选择只使用训练/验证信息；
- 特征重要性、SHAP 和筛选不得使用最终留出期；
- 同日收盘特征不能按同日收盘成交。

## 7. 工程实现块

计划中的最小接口：

- dataset/feature view builder；
- 时间滚动 splitter；
- sklearn 风格 model adapter；
- deterministic seed 与 config schema；
- prediction artifact schema；
- model comparison 与 promotion gate；
- 单元、泄漏、回归和 CLI smoke 测试。

具体模块路径先经过代码设计审查，不在计划中强制固定。

## 8. 验收标准

- [ ] 所有实验绑定冻结数据与特征版本；
- [ ] 透明模型与现有静态基准完整；
- [ ] 至少 36 个非重叠 OOS 月；
- [ ] 预处理、调参和模型选择无未来信息；
- [ ] 报告预测、经济、成本和稳定性四层结果；
- [ ] 消融和负向检查完成；
- [ ] 最终留出期仅使用一次；
- [ ] 结论可为“不支持 ML 增量”；
- [ ] 结果不表述为实盘可得收益。

## 9. 晋级条件

只有当 LightGBM 相对透明基准在多个 OOS 窗口表现出稳定、可解释、成本后仍成立的增量，且过拟合审计未触发，才进入 P4/P5 的候选输入。否则保留简单模型。
