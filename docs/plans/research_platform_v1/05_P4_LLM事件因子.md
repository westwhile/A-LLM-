# P4 / 科研 R1：LLM 事件因子实施计划

> P4 是兼容性工程编号；本模块现在是个人科研第一方向。完整顺序见 [三大科研主线与 AI 工程分工](13_三大科研主线与AI工程分工.md)。

## 1. 中央研究问题

> 在透明结构化基准与固定收益评价器下，事件标签或文本 Embedding 是否提供独立、稳定、PIT 合格且成本后成立的增量预测信息？

“使用 LLM”不是创新结论；只有经过对照、消融和真实 OOS 检验的独立增量才是研究结果。

## 2. 启动门槛

- P1 透明传统/结构化基准已 `accepted`；
- P2 的文本数据、特征和实验登记合同可用；
- 线性模型与低搜索预算 LightGBM evaluator 的数据、切分、超参数和指标已冻结；该 evaluator 只测量表示增量，不在 R1 中开展广泛 ML 调参；
- 真实新闻/公告数据来源、许可、缓存、衍生输出和展示权限已审查；
- `event_time`、`publish_time`、`available_time`、抓取时间和证券映射可审计；
- 历史文本不是事后回填或当前网页快照；
- 人工复核标签集、抽样方案和一致性标准已定义；
- 使用外部模型、API 或下载权重前另行取得网络与数据授权。

若任一门槛缺失，P4 状态保持 `blocked`。

## 3. 数据工作包

### P4-D1：事件数据合同

固定主键、原文哈希、来源 URL/文件、发布时间、可用时间、证券、事件类型、语言、去重组和许可类别。

### P4-D2：PIT 与去重

- 只允许 `available_time <= signal_cutoff` 的事件；
- 转载、标题变体和多源重复不得被重复计数；
- 公告更正和新闻更新保留版本链；
- 证券映射失败、模糊或跨公司事件进入审计队列。

### P4-D3：人工复核集

按时间、行业、事件类型和模型置信度分层抽样。记录标注指南、复核者、一致性、争议和最终状态。未通过门槛的标签不进入信号。

## 4. 实验阶梯

### R1/P4-E0：无文本对照

使用 P1 透明结构化特征和冻结 evaluator，禁止在看到不同文本表示结果后重新选择 evaluator 参数。

### R1/P4-E1：规则/词典基准

建立不依赖 LLM 的事件类型、关键词或情绪基准，用于判断复杂模型是否真正增加价值。

### R1/P4-E2：结构化 LLM 标签

使用固定 prompt、model/version、schema、cache key 和人工抽查门槛输出事件类型、方向、强度和置信度。置信度仅是模型元数据，不等于投资成功概率。

### R1/P4-E3：预训练文本 Embedding

冻结模型版本和文本预处理，将 Embedding 作为输入特征；不得在全样本上监督微调或降维后再做 OOS 切分。

### R1/P4-E4：增量与消融

比较：

- 结构化因子；
- 结构化因子＋规则事件；
- 结构化因子＋LLM 标签；
- 结构化因子＋Embedding；
- 移除事件时间/行业等控制后的稳健性；
- 随机打乱事件日期/证券映射的负向对照。

### R1/P4-E5：RAG、Transformer 与领域微调候选

先检验 PIT RAG；只有 E2/E3/RAG 至少一个显示稳定增量、标签许可与规模足够、算力和复现方案明确时，才立项 Transformer 或 LoRA。不得默认建设“金融基础模型”。

## 5. 模型与缓存治理

- 原文、prompt、系统指令、模型 ID、权重/服务版本、温度和解析 schema 全部登记；
- cache 不允许在 prompt/model/schema 变化后复用；
- API 输出失败、拒答和格式错误必须留痕；
- 不把授权文本、凭据或个人金融数据发送给未批准外部服务；
- 生成式解释不能替代结构化预测与统计证据。

## 6. 评价与验收

- 标签层：覆盖率、准确率/一致性、混淆、置信度校准和时间稳定性；
- 预测层：相对冻结无文本 evaluator 的增量 IC/Rank IC、OOS 损失和稳定性；
- 经济层：成本后分组/组合增量、换手、容量和延迟衰减；
- 稳健性：年度、行业、事件类型、模型版本和极端事件分层；
- 多重尝试：全部模型/prompt/特征版本进入 experiment registry。

## 7. 核心产物

- 事件数据与 PIT 合同；
- 人工复核集与标注说明；
- 规则、LLM 标签和 Embedding 三层基准；
- prompt/model/cache 审计；
- 增量、消融、成本与稳健性报告；
- 可被 Research Package 引用的模型与证据 manifest。

## 8. 验收标准

- [ ] 文本来源和使用许可已批准；
- [ ] 事件可用时间和去重可审计；
- [ ] 人工复核门槛通过；
- [ ] 规则基准、LLM 标签和 Embedding 对照完整；
- [ ] 结构化特征与 evaluator 参数在表示比较期间保持不变；
- [ ] 所有 prompt/model 尝试已登记；
- [ ] 负向对照未暴露时间或映射泄漏；
- [ ] 增量结论在多个 OOS 窗口成立，或明确得出“不支持”；
- [ ] 未自动把 LLM 输出转为真实财务决策。

## 9. 文献门禁

FinBERT、BloombergGPT、金融文本资产定价及其他论文的题名、年份、方法和可用权重必须在正式研究方案中单独联网核验。本计划不把未核验引用作为实现依据。

## 10. 向 R2 交接

R1 只交付冻结的 `TextRepresentationArtifact` 及其增量/失败证据。若复杂表示未通过，交付规则标签或“无文本”基准也属于合格结果。R2 不得重新查看 R1 最终留出期选择表示。
