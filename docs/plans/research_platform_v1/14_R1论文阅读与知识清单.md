# R1：LLM Event Factor 论文阅读与知识清单

> 状态：`learning_plan`
>
> 文献核验日期：2026-08-11
>
> 适用范围：`R1 LLM Event Factor`，即“金融文本 → 事件/语义表示 → 冻结收益评价器 → Alpha 增量”。

## 1. 这份清单解决什么问题

R1 不是“用一个更大的 LLM 判断新闻利好或利空”，而是研究：

> 在真实来源、严格事件时点、去重、实体映射和固定收益评价器下，哪一种金融文本表示能够提供稳定、独立、可复现的样本外收益预测增量？

因此，阅读必须同时覆盖四类知识：

1. 金融文本为什么可能预测收益，以及市场反应的经济机制；
2. 如何把文本变成词典分数、事件结构、Embedding 或 LLM 表示；
3. 中文金融事件和 A 股新闻有哪些独有的数据问题；
4. 如何在 PIT、OOS、消融和负向对照下判断表示是否真的形成 Alpha。

本文中的“优秀”不只指模型新或指标高，也包括：问题重要、方法可解释、数据与时点清楚、对照合理、结果能被证伪或对本项目可迁移。

## 2. 文献状态标记

- `J`：已发表的同行评审期刊论文；
- `C`：已发表的同行评审会议论文；
- `WP`：工作论文、预印本或学位论文，结论和版本仍可能变化；
- `B`：数据集或评测基准论文；
- `设计阅读`：用于理解架构或评测，不代表模型权重、语料或许可证可直接用于本项目。

工作论文中的收益、Sharpe 或组合表现只作为待复核证据，不能直接写成 A 股研究结论。

## 5. 推荐学习顺序与阶段产物

| 阶段 | 学习内容 | 建议论文 | 必须形成的产物 |
|---|---|---|---|
| S0 | Transformer/BERT 和金融文本基础 | Vaswani；BERT；Malo | 一页概念图；解释 token、attention、pooling、fine-tuning |
| S1 | 金融文本与市场反应机制 | Tetlock 2007/2008；Loughran–McDonald；Jegadeesh–Wu；Heston–Sinha；Li et al. 中国股市情绪 | 两条可证伪机制假设；规则/词典基准设计；区分信息文本与投资者状态文本 |
| S2 | 从分类到表示 | Araci；Yang FinBERT；Sentence-BERT；SimCSE；FinMTEB | 候选模型卡；标签 vs Embedding 小实验方案 |
| S3 | 中文事件结构 | DCFEE；Doc2EDAG；FINEED/MACK；EFSA | 事件 schema、标注指南和 50–100 条 gold set 计划 |
| S4 | RAG 与知识时点 | RAG；DPR；FinQA；TAT-QA | PIT knowledge snapshot、检索指标和未来检索反例 |
| S5 | 文本 Alpha 与研究设计 | Ke–Kelly–Xiu；Tan–Wu–Zhang；Lopez-Lira–Tang；Ludwig et al. | R1 预注册、冻结 evaluator、消融/负向对照矩阵 |

只有 S0–S3 的退出标准完成后，才建议实际进入 RAG；只有简单 Embedding 或 RAG 显示稳定增量后，才考虑 Transformer 微调或 LoRA。

`Measuring China's Stock Market Sentiment` 建议放在 S1 完成 Tetlock 与 Loughran–McDonald 后阅读。阅读时重点比较“媒体/公司新闻携带的信息”与“股吧帖子反映的投资者状态”：前者更接近 R1 Event Factor，后者更适合作为市场状态、注意力、分歧或异质性控制。不要把两类文本合并成同一个情绪变量。

## 6. 知识清单

### 6.1 金融与资产定价基础

- [ ] 简单收益、对数收益、超额收益和异常收益的区别；
- [ ] 公司新闻事件日、形成期、持有期和执行日如何对齐；
- [ ] 横截面预测与时间序列预测的区别；
- [ ] 信息进入价格、投资者注意力、低反应、过度反应和反转机制；
- [ ] size、value、momentum、liquidity、industry 等必要控制；
- [ ] IC、Rank IC、OOS loss/OOS R² 与组合收益各回答什么问题；
- [ ] 收益预测不等于可交易 Alpha：成本、换手、容量和延迟必须单独检验。

### 6.2 NLP 与语言模型基础

- [ ] token、tokenizer、词表和中文分词/子词边界；
- [ ] self-attention、位置编码、encoder 与 decoder；
- [ ] masked language modeling、预训练、继续预训练和任务微调；
- [ ] `[CLS]`、mean/max pooling 和句向量的差异；
- [ ] classification logit、hidden state、Embedding 与生成式标签不是同一产物；
- [ ] 对比学习中的正样本、hard negative、温度参数和表示坍塌；
- [ ] prompt、zero-shot/few-shot、LoRA 与完整微调的适用边界；
- [ ] 置信度校准：模型自报 confidence 不等于正确概率或收益成功概率。

### 6.3 金融文本任务

- [ ] 情绪分析：positive/neutral/negative 及其金融语境错配；
- [ ] 实体识别与公司/证券历史映射；
- [ ] 事件类型、触发词、论元、角色和跨句事件；
- [ ] entity-level、event-level 与 document-level 情绪的区别；
- [ ] 关系抽取：客户、供应商、竞争者、行业和政策关系；
- [ ] 事件方向、强度、持续期、兑现条件和不确定性；
- [ ] “是否已 price in”是待检验变量，不是 LLM 可以直接判真的事实。

### 6.4 中文新闻与 A 股数据纪律

- [ ] 公告发布时间、首次抓取时间、可得时间和修订时间分别保存；
- [ ] 盘中、盘后、非交易日发布对应的最早可执行时点；
- [ ] 公司简称、曾用名、股票代码变更和一文多公司的实体映射；
- [ ] 新闻转载、标题改写、同事件多稿和旧信息重组的去重；
- [ ] 公告、媒体新闻、研报和社交文本不能混为同一种来源；
- [ ] 英语 FinBERT 不能未经验证直接替代中文金融模型；
- [ ] 停牌、涨跌停、ST、退市和幸存者偏差进入可交易性检查；
- [ ] 文本缺失是 coverage 状态，不能自动填成中性事件。

### 6.5 Embedding 与表示工程

- [ ] 句、段落、文档、事件和公司—日五种聚合粒度；
- [ ] cosine similarity、nearest neighbor、聚类与检索指标；
- [ ] 事件级多篇新闻如何聚合，是否保留来源和时间衰减；
- [ ] PCA/AutoEncoder 降维只能在训练折拟合；
- [ ] 模型、tokenizer、预处理、pooling 和维度版本必须冻结；
- [ ] embedding cache key 包含原文哈希和全部模型/预处理版本；
- [ ] 标签、Embedding 和规则分数要在同一固定 evaluator 中公平比较；
- [ ] 通用语义相似度高不等于收益预测信息强。

### 6.6 RAG 与知识库

- [ ] chunking、metadata、BM25、dense retrieval、hybrid retrieval 和 reranking；
- [ ] Recall@k、MRR、nDCG 与最终生成正确率的区别；
- [ ] 公司公告、财报和历史事件的 `as_of_time` 与知识库 snapshot；
- [ ] 事件发生之后写成的总结不得被历史检索；
- [ ] 每个输出保留检索片段、来源、知识库版本和检索时间；
- [ ] 检索错误与生成错误分开归因；
- [ ] RAG 增量需要与“无检索”“BM25”“dense-only”对照；
- [ ] 回答更流畅不是验收指标，引用正确和收益增量才是。

### 6.7 研究设计与统计检验

- [ ] 在比较文本表示前冻结 Linear/LightGBM evaluator 和超参数空间；
- [ ] 时间切分、walk-forward、重叠标签下的 purge/embargo；
- [ ] 无文本、规则词典、结构化标签、通用 Embedding、金融 Embedding、PIT RAG 六层对照；
- [ ] 仅标题、去公司名、随机配股、随机移位和未来知识库检测等负向对照；
- [ ] 行业、年度、事件类型、公司规模和流动性分层；
- [ ] 覆盖率、实体/事件 F1、校准、IC、OOS loss、成本后收益同时报告；
- [ ] prompt、模型、pooling、降维和聚合的每次尝试都计入 trial family；
- [ ] 多重尝试、最终留出和停止规则在看结果前登记；
- [ ] 允许结论为“不支持复杂表示提供稳定增量”。

### 6.8 可复现性、许可与治理

- [ ] 文本来源、许可、转载/缓存/衍生使用权和可发布字段；
- [ ] 原文哈希、source URL/file、抓取时间和修订链；
- [ ] 模型 ID、权重/服务版本、tokenizer、prompt、temperature 和 schema；
- [ ] API 拒答、失败、格式错误和重试全部留痕；
- [ ] gold set 的抽样方法、标注指南、复核者和争议裁决；
- [ ] inter-annotator agreement 及低一致性类型的停止/合并规则；
- [ ] 外部模型训练截止和可能的数据污染风险；
- [ ] LLM 产物只能形成研究特征，不能直接进入 PFROS 事实层或触发交易。

## 7. 建议的动手学习任务

1. **规则基准**：在合规的小样本上复现 Loughran–McDonald/关键词分数，并记录错误类型；
2. **FinBERT 基准**：比较通用情绪、FinBERT 和人工标签，重点分析中文/英文领域错配；
3. **Embedding 任务**：用 Sentence-BERT/候选中文模型完成相似新闻检索和同事件聚类；
4. **中文事件 gold set**：设计 50–100 条公司—事件—方向—强度—时点标注，并做双人或双轮复核；
5. **固定 evaluator**：冻结 Linear/LightGBM，用同一切分比较无文本、标签和 Embedding；
6. **PIT RAG 反例**：故意允许未来公告进入检索，展示指标被虚高，再用 snapshot gate 阻断；
7. **负向对照**：随机配股、事件日期后移和去公司名，确认管线能暴露泄漏或伪相关；
8. **小型研究报告**：只报告增量、稳定性、覆盖、成本和失败，不追求挑选最好看的 Sharpe。

这些任务是学习/研究设计，不代表已授权下载模型、抓取联网数据或运行真实投资实验。
