# Argument Map：科研平台与 PFROS 融合计划

## 1. 科学张力

### 已知

- A-LLM 已有较完整的工程与研究治理能力；
- 真实数据工程门禁已运行并当前通过；
- 传统动态模型、回测和晋级审计已有工程实现；
- PFROS 已形成“事实—研究—决策”隔离架构。

### 未知

- 现有传统/动态模型是否在真实 OOS 中成立；
- ML 相对透明基准是否有稳定增量；
- LLM 事件表示是否有独立增量；
- 预测增量能否在成本和约束下转化为组合价值；
- 研究证据如何安全进入个人决策而不被误用。

### 为什么重要

如果不先冻结真实基准和成熟度门禁，增加模型只会扩大过拟合、证据漂移和个人决策误用风险。

## 2. 中央研究问题

在严格 PIT、预注册 OOS、交易成本与执行约束下，金融文本表示是否提供增量、该表示能否与结构化特征形成 ML Alpha，以及冻结预测能否转化为稳健组合并安全封装为个人决策候选？

## 3. 中央论点

正确路线不是扩大单体量化系统，而是先建立冻结的真实基准，再依次研究 LLM Event Factor、ML Alpha 和组合转化；其余工程由 AI 按需实现，通过成熟度与 Research Package 将可接受证据传给独立 PFROS。

## 4. 支撑论点

### A：真实基准优先

- 证据：当前只有 gate 与工程证据，没有真实研究 run；
- 推论：P0/P1 必须早于新模型；
- 限制：gate passed 仍需签署、冻结和 warning 说明。

### B：复杂模型必须相对简单模型证明增量

- 证据：现有静态、IC、Kalman/HMM/GARCH/DCC 可作为对照；
- 推论：ML、LLM、BL 按实验阶梯推进；
- 限制：结果可能不支持复杂模型。

### C：科研与个人金融事实必须隔离

- 证据：PFROS 架构已有事实平面与 Research Registry；
- 推论：使用 Research Package、脱敏持仓视图和人工批准；
- 限制：个人执行结果不是天然无偏训练数据。

### D：扩展方向必须服务明确研究问题

- 证据：用户提出的异常检测、RAG、图、多模态、基础模型、Agent、RL 等跨越多个独立研究方向；
- 推论：重组为 16 个模块并分 A/B/C 层，每次只推进一个主模块；
- 限制：模块存在不代表应全部实现，负结果和停止也是合格产出。

### E：预测、机制和决策治理是三条不同证据链

- 预测链回答是否有 OOS 增量；
- 因果链回答在明确识别假设下是否存在处理效应；
- 治理链回答证据是否可复现、可安全进入个人决策；
- 三条链可以共享数据合同，但不能互相替代结论。

### F：R1 使用固定 evaluator，R2 才研究收益模型

- 证据：文本 Alpha 需要下游收益任务，完全没有预测器无法评价金融价值；
- 推论：R1 固定 Linear/LightGBM evaluator，只改变文本表示；
- 限制：R1 结论只支持表示在该冻结评价协议下的增量；
- R2 再固定 R1 表示，系统比较 ML 模型，从而隔离两类贡献。

## 5. 替代解释与反对意见

- 也许无需 ML，简单 IC/风险模型已经足够；因此简单模型保留正式候选身份；
- 平台化可能拖慢研究；因此只做离线轻量 Registry；
- LLM 增量可能来自时间/映射泄漏；因此要求规则基准、负向对照和人工复核；
- 个人决策改善可能来自人工纪律而非模型；因此不作因果收益声明。
- purging/embargo 可能对已非重叠月度标签冗余；因此按标签区间决定；
- 异常模型可能把真实极端行情误判为错误；因此只生成审查队列；
- foundation/Agent/RL 可能消耗大量资源却无增量；因此不设日历里程碑并使用停止条件。

## 6. 最终推进逻辑

P0/P1 建立可否定的真实基准；P2 与模块 01/03/07/14 保障数据、验证、复现与交接；R1/P4 固定评价器研究文本表示；R2/P3 固定表示研究 ML Alpha；R3/P5 固定预测研究组合转化；PFROS M0–M4 建立可信事实，M5–M7 才允许受控接入和复盘。其余模块只按 R1–R3 的明确需求由 AI 辅助实现或另行立项。
