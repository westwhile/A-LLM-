## 1. 计划包定位

本计划包把两条长期主线连接起来，但不合并两个仓库：

- `A-LLM-` 是量化科研实验室，负责产生可复现、可审计的研究证据；
- PFROS 是个人金融事实、研究登记、人工决策与复盘系统；
- 两者只通过版本化 `Research Package` 交接；
- 任何模型或 AI 输出都不能直接写入个人金融事实或触发交易。

## 4. 专项研究模块

模块文件把用户给出的 20 类研究方向重新组织为 16 个可学习、可证伪、可实施的专题。完整索引见 [modules/README.md](modules/README.md)。

- 近期必做：离线特征库、PIT/金融交叉验证、结构化 ML Alpha、回测过拟合控制、实验管理；
- 条件成熟：异常检测、LLM 文本 Alpha、组合优化、风险/压力、因果 ML；
- 长期探索：另类数据、多模态、知识图谱、基础模型、Agent、合成数据；
- 治理主线：隐私、安全和 Human-in-the-loop 从 PFROS 设计第一天启用。

## 5. 规划依据与 QA

`planning_basis/` 保存本计划使用的事实边界、证据等级、论证结构、章节合同和 QA 结果。这些文件用于防止把拟实施内容误写为已完成结果。

## 6. 状态词

- `planning`：仅完成设计；
- `ready`：前置条件和人工批准齐全，可以实施；
- `in_progress`：已有受控任务正在执行；
- `blocked`：存在明确未满足门禁；
- `review`：产物已形成，等待独立检查或人工批准；
- `accepted`：验收证据与批准完整；
- `rejected`：结论或实现未达到门槛，不得晋级。

不得仅依据旧计划、AI 自报、测试存活或单个指标把状态更新为 `accepted`。
